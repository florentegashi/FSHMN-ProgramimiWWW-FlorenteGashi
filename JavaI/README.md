# Java I – Pasaporta Digjitale

## Çfarë realizova

Krijova një pasaportë digjitale për një personazh të sajuar që
kandidon si udhërrëfyes i kampusit.

Faqja përmban:
- prezantimin e personazhit;
- 3 aftësi;
- faqen "Rreth";
- lidhje relative mes dy faqeve.

## Hapat e hapjes

1. Hap repository-n `programimi-www`.
2. Hape folderin `JavaI`.
3. Hap `index.html` për të parë faqen kryesore.

## Hyrje → Rezultat i pritur → Rezultat i marrë

### Hyrje
Hapen skedarët `index.html` dhe `rreth.html` përmes serverit lokal.

### Rezultat i pritur
Të dyja faqet hapen dhe lidhjet vajtje/kthim funksionojnë pa gabimin 404.

### Rezultat i marrë
Të dyja faqet u hapën me sukses dhe lidhjet relative funksionuan.
