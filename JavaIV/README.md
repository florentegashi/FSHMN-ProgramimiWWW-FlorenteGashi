# Java IV – Festivali që përshtatet në çdo ekran

## Përshkrimi

Ky projekt paraqet një faqe web për një festival shkencor, e cila përshtatet me madhësi të ndryshme të ekranit. Faqja përmban gjashtë karta aktivitetesh, menu navigimi dhe imazh fleksibil.

## Përmbajtja

- Gjashtë karta me titull, kategori, orar dhe lidhje për detaje.
- Menu navigimi e realizuar me Flexbox.
- Organizimi i kartave me CSS Grid.
- Pamje responsive për telefon, tablet dhe kompjuter.
- Navigim me tastierë dhe fokus të dukshëm.

## Hapja e projektit

1. Hap folderin `JavaIV`.
2. Hap fajllin `index.html` në shfletues.
3. Për testim përdor Developer Tools (F12).


## Reflektim

**Kur përdoret Flexbox dhe kur Grid?**

Flexbox përdoret për organizimin e elementeve në një drejtim, si menuja e navigimit, ndërsa Grid përdoret për organizimin e elementeve në rreshta dhe kolona, si kartat e aktiviteteve.


**Referencë:** Fundamentals of Web Development, kapitujt 6–7.
